# Lifecycle workflow

1. Preview and initialize a clean Git repository.
2. Commit repository profile, schemas, templates, and agent guidance.
3. Prepare the smallest deterministic context pack for a mission.
4. Record mission results, checks, files, SHAs, and inspectable evidence.
5. Create learnings only as proposals with proposer attribution.
6. Evaluate evidence, novelty, conflicts, confidence, and encoding.
7. Curate a review and patch recommendation.
8. Let a human approve any promotion, merge, stale marker, supersession, or stronger encoding.
9. Validate and commit the reviewed result.
