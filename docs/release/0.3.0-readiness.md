## Canonicalization

The standalone repository owns all implementation, schemas, templates, and tests. The installed Codex skill contains instructions, agent metadata, references, and an install manifest only. `project-brain doctor` reports zero implementation drift and supplies a repair command.

## Known limitations

- `core.py` still contains several cohesive domains awaiting behavior-preserving extraction.
- Mission closure retains the legacy inline `--learning` option; the dedicated proposal command is preferred.
- No semantic retrieval, organizational memory, provider API, web UI, database, vector store, worker, model dependency, or Mission Control integration exists.
- The Python 3.8 standard-library venv bootstrapped pip 19.2.3, which required a pip upgrade before modern dependency installation.
