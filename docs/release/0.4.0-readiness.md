# Project Brain 0.4.0 release readiness

Project Brain 0.4.0 adds consumer contract 1.0 without changing the repository artifact schema major.

- Core package and Codex skill adapter: 0.4.0.
- Consumer contract: 1.0.
- Repository artifact schema: 2.5.0.
- Structured operations: detection, validation, summary, context preparation and reading, closure, learning
  proposal and evaluation, curation, knowledge listing, health, and diagnostics.
- Context packs expose separate completeness and precision fields, deterministic revision/checksum evidence, and
  explicit missing-context accounting. They never claim optimality.
- Knowledge health is a multi-signal observation, not a synthetic score.
- Automatic initialization and learning promotion remain disabled.

The package suite, command/library parity tests, disposable-repository dogfood, installed-skill diagnostics, and
Mission Control adapter tests must pass before release. Publishing and deployment are separate explicit actions.
